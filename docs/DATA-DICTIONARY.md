# 访视与冻结定义

样例均为虚构编号，无身份信息。受试者入组日期由subjects表唯一确定，记录中的入组基准必须完全一致。采样日期和入组日期均转为Asia/Shanghai日历日期，差值为访视日；时刻先统一UTC。
方案选择按当前受试者assignment和该次发生时刻查半开生效窗，匹配必须唯一，不能使用全局最新方案。v1访视V1=[5,10)、V2=[12,17)；v2为[6,11)、[13,18)。受试者00001于10月10日转v2，其他受试者仍用v1。
PRIMARY计入访视完成，RETEST只替代该次测量值。首次记录必须唯一且在访视窗内。缺首次访视、重复首次和窗外访视均阻断，复检不能填补漏访或消除原偏离。
复检须引用同受试者同访视的PRIMARY，晚于原采样且不超过72小时，版本必须更高。同最高版本复检冲突时保留原结果并阻断。所有检验值以mg/dL输出，g/L乘100。
锁库须所有规定访视完成，无偏离、复检问题和隔离行，且质量抽查名单已定。冻结包包含每条选定结果、原始行号、方案版本与访视窗，sampling.json 另存抽查名单与锁库依据。此工具只验证试验数据完整性，不做诊断判断或生产锁库。

# 锁定批质量抽查定义

锁定批固定抽取八名受试者。偏离、复检问题、隔离记录涉及的受试者构成风险面，必须全部纳入名单；风险席上限为六，至少保留两个无异常对照位，高风险对象不得占满名额。风险面超过六名或受试者不足八名时名单未定，锁库与归档不得放行。无风险批八席全部作为代表性对照，名单仍然确定。

受试者归因以原始字段为准：复检问题通过记录号索引回受试者（含被隔离的孤儿复检），隔离行取 raw.subject 而非编号前缀，未入组的伪受试者不进入名单。同席内按 sha256(qa-sampling-2026.11|批号|受试者) 令牌升序确定性选取，全程无随机数。

批号由源数据字节、上下文与规则版本的摘要决定。同批号重跑名单逐字节一致，不新增不改换；源数据或规则更新生成新批号，旧名单与旧锁库依据随旧批保留但不再作为当前依据；重算失败时旧批不被覆盖。冻结包 sampling.json 含名单、取舍规则、锁库依据、源摘要与规则版本，封存哈希覆盖抽查结果。
